# Kaggri-Trade

Prototype giao diện Kaggri-Trade tích hợp luồng Buyer, Vendor và đăng nhập theo vai trò.

## Chạy dự án

```powershell
cd docs
python -m http.server 8080
```

Mở <http://localhost:8080/> trong trình duyệt.

Xem thêm hướng dẫn và giới hạn của prototype tại [`docs/README.md`](docs/README.md).
